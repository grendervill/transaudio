# Вендорные ассеты макетов

## Шрифты

Файлы `.woff2` и `fonts.css` получены из Google Fonts. Все семейства распространяются по лицензии [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/):

- Unbounded — [Google Fonts](https://fonts.google.com/specimen/Unbounded)
- Golos Text — [Google Fonts](https://fonts.google.com/specimen/Golos+Text)
- Literata — [Google Fonts](https://fonts.google.com/specimen/Literata)
- Onest — [Google Fonts](https://fonts.google.com/specimen/Onest)
- IBM Plex Mono — [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Mono)
- Lora — [Google Fonts](https://fonts.google.com/specimen/Lora)

Пересобрать набор: `python3 scripts/fetch-mockup-assets.py`.

## Иконки

`../icons/lucide.svg` собран из набора [Lucide](https://lucide.dev) (пакет `@iconify-json/lucide`, версия 1.2.68). Lucide распространяется по лицензии ISC. Используется один набор иконок во всех четырёх макетах.
