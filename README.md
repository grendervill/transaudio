# Transaudio

Локальная транскрибация аудио и видео на Tauri и NVIDIA Parakeet TDT 0.6B v3. Файлы обрабатываются по очереди, текст можно читать прямо в приложении, а готовые расшифровки сохраняются в выбранную папку. Аудио и видео не покидают компьютер.

Визуальное направление — **Tape Room**: тёмная полевая студия с плотной очередью, тёплым янтарным акцентом и расшифровкой как рабочим документом.

## Что уже работает

- Три экрана: **Файлы**, **Транскрипция**, **Экспорт**.
- Добавление файлов через drag-and-drop и системный диалог.
- Последовательная обработка нескольких файлов.
- Отдельная шкала текущего файла и общая шкала очереди.
- Пауза и продолжение между фрагментами расшифровки.
- Первый запуск с разрешением на загрузку Parakeet V3; разрешение сохраняется, модель потом запускается вместе с приложением.
- Загрузка модели с проверкой SHA-256 и распаковкой в `$APP_DATA`.
- Локальная расшифровка через ONNX Runtime без облака.
- Автоматическое сохранение Markdown после каждого файла.
- Экспорт выбранных расшифровок в Markdown, SRT или TXT.
- Смена папки результатов в настройках.
- Обработка ошибок отдельного файла без остановки всей очереди.

## Запуск

Нужны Node.js 20.19+, Rust 1.90+ и зависимости Tauri 2 для вашей ОС. Подробности — в [docs/building.md](docs/building.md).

```bash
npm ci
npm run tauri dev
```

При первом запуске приложение спросит разрешение на загрузку модели (~640 МБ на диске). Если FFmpeg отсутствует, он будет автоматически подготовлен при первой обработке видео/аудио (через `ffmpeg-sidecar`).

## Проверка

```bash
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build
```

## Где лежат данные

`$APP_DATA`:

- macOS: `~/Library/Application Support/com.transaudio.desktop`
- Windows: `%APPDATA%\com.transaudio.desktop`
- Linux: `~/.local/share/com.transaudio.desktop`

Внутри: `settings.json`, `models/parakeet-v3-int8`, `bin/` (FFmpeg), временный `cache/`.

Расшифровки по умолчанию сохраняются в `Documents/Transaudio`.

## Технический стек

- Tauri 2 + Rust
- React 19 + TypeScript + Vite 8
- `transcribe-rs 0.3.12` + `ort 2.0.0-rc.12`
- Parakeet TDT 0.6B v3 int8 ONNX
- FFmpeg для извлечения аудио
- Vitest + Testing Library, Rust unit tests

`ort` закреплён на `=2.0.0-rc.12`: `transcribe-rs 0.3.12` несовместим с API более новых release-candidate версий.

## Ограничения первой версии

- Нет диаризации спикеров: модель не определяет, кто говорит.
- Нет ручного редактирования текста.
- Очередь и результаты живут в памяти текущей сессии; после перезапуска нужно добавить файлы снова. Markdown-копии уже готовых файлов остаются на диске.
- Нет изменения порядка очереди.
- Кроссплатформенные сборки проверяются через CI; эта машина использовалась для реальной проверки macOS-сборки.
