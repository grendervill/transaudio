# Transaudio

Локальная расшифровка аудио и видео на Tauri. 12 моделей из каталога Handy,
разделение спикеров, очередь файлов и экспорт в Markdown, SRT или TXT. Аудио,
видео и текст остаются на компьютере.

Визуальное направление — **Tape Room**: тёмная полевая студия с плотной
очередью, тёплым янтарным акцентом и расшифровкой как рабочим документом.

## Что работает

- Три экрана: **Файлы**, **Транскрипция**, **Экспорт**.
- Drag-and-drop и системный выбор файлов, последовательная очередь.
- Отдельный прогресс текущего файла и общий прогресс очереди, пауза.
- Готовые файлы не расшифровываются повторно; клик по файлу открывает его текст.
- Каталог моделей Handy с реальными WER и скоростью из их бенчмарков.
- Рекомендации: GigaAM v3 — для русского, Parakeet Unified English — для английского.
- Разделение спикеров (sherpa-onnx) со сценариями «интервью», «встреча», «много участников».
- Плашки «Спикер 1/2» в интерфейсе и в экспорте.
- Автосохранение Markdown после каждого файла; экспорт MD/SRT/TXT.
- Загрузка моделей по требованию с проверкой SHA-256; выбор модели сохраняется.
- Диагностический лог `transaudio.log` в каталоге данных.

- **Canary** требует явно указать язык записи; остальные модели определяют язык сами.

## Спикеры

- Модели диаризации: pyannote segmentation 3.0 и CAM++ (~35 МБ), скачиваются при
  первом включении.
- Сценарии: «Интервью / диалог (2–4)» по умолчанию, «Встреча (4–6)»,
  «Много участников (7+)», «Авто». Сценарий задаёт порог кластеризации и
  верхнюю границу числа спикеров: в интервью не появится «Спикер 12».
- «Сколько голосов» — точное число спикеров, если оно известно (2–6).
  Приложение сведёт лишние кластеры к выбранному числу.
- Мелкие кластеры длительностью меньше 1% речи (минимум 2 с) не считаются
  отдельными спикерами и присоединяются к ближайшему голосу.
- Запись режется по репликам спикеров, каждая реплика расшифровывается отдельно —
  подписи работают и с моделями без таймкодов.
- Для файлов длиннее 2 часов диаризация отключается: аудио читается в память
  целиком. Обычная расшифровка при этом работает.

## Запуск

Нужны Node.js 20.19+, Rust 1.90+, CMake и C++ toolchain (движок
`transcribe-cpp` собирается из исходников). Подробности — в
[docs/building.md](docs/building.md).

```bash
npm ci
npm run tauri dev
```

При первом запуске выберите модель; скачается только она. FFmpeg при
необходимости скачивается автоматически при первой обработке.

## Проверка

```bash
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build
```

## Где лежат данные

`$APP_DATA`:

- macOS: `~/Library/Application Support/com.transaudio.desktop`
- Windows: `%APPDATA%\com.transaudio.desktop`
- Linux: `~/.local/share/com.transaudio.desktop`

Внутри: `settings.json`, `models/<id>` (GGUF), `models/diarization`, `bin/`
(FFmpeg), временный `cache/`, `transaudio.log`.

Расшифровки по умолчанию сохраняются в `Documents/Transaudio`.

## Обновление с 0.1.x

Движок заменён с ONNX Runtime на transcribe.cpp (как в Handy). Parakeet нужно
один раз скачать заново в GGUF; старая папка `models/parakeet-v3-int8` удаляется
после установки новой версии. Остальные настройки и папка результатов
сохраняются.

## Ограничения

- Нет переименования спикеров и голосовых профилей между файлами.
- Canary не определяет язык автоматически.
- Нет ручного редактирования текста и сохранения очереди между перезапусками.
- Нет изменения порядка очереди.
- Сборки не подписаны: macOS Gatekeeper и Windows SmartScreen предупреждают.
- Linux требует Ubuntu 24.04+ (glibc 2.39) из-за предсобранного ONNX Runtime,
  который всё ещё используется sherpa-onnx.

## Если модель не скачивается

Приложение сразу показывает состояние загрузки, а при сбое — причину и кнопку
«Повторить». Кроме моделей и FFmpeg, оно не обращается к сторонним сервисам.

Что проверить:

- доступ к `https://huggingface.co` и `https://github.com` (HTTPS, порт 443);
- брандмауэр и антивирус: разрешите приложению исходящие соединения;
- корпоративный прокси: задайте `HTTPS_PROXY` и `HTTP_PROXY` перед запуском;
- при ошибке контрольной суммы удалите папку модели в `models/` и повторите.

Диагностический лог лежит рядом с настройками:

- macOS: `~/Library/Application Support/com.transaudio.desktop/transaudio.log`
- Windows: `%APPDATA%\com.transaudio.desktop\transaudio.log`
- Linux: `~/.local/share/com.transaudio.desktop/transaudio.log`

В логе есть точный URL, HTTP-статус, этапы загрузки и текст сетевой ошибки.
