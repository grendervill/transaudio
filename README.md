# transaudio

Локальная транскрибация аудио и видео на Tauri и модели Parakeet V3. Репозиторий создан для программы, которая обрабатывает файлы по очереди, показывает расшифровку внутри приложения и сохраняет готовые тексты в выбранную папку.

Сейчас здесь лежат **четыре интерактивных макета интерфейса**. Исходной реализации Tauri ещё нет — сначала выбираем визуальное направление, затем вокруг него собирается приложение.

## Посмотреть макеты

Из корня репозитория:

```bash
./scripts/preview.sh
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) — это страница выбора направления. Можно прокрутить все четыре макета и открыть любой из них.

Если скрипт не подходит, поднимите статический сервер вручную:

```bash
python3 -m http.server 4173 --directory mockups
```

> Открывать HTML-файлы напрямую через `file://` не стоит: общий набор иконок подключён как внешний SVG-спрайт, которому нужен HTTP-сервер.

## Четыре направления

| Макет | Характер | Для кого |
|---|---|---|
| **Tape Room** | Тёмный полевой рекордер с янтарным акцентом, плотной очередью и плёночной подачей | Большие архивы, длинная работа за столом |
| **Редакция** | Светлая журнальная вёрстка с крупной антиквой и синей полосой выпуска | Журналисты, исследователи, авторы |
| **Пульт** | Трёхпанельная рабочая консоль с сегментированными шкалами | Ежедневная пакетная обработка |
| **Тихая комната** | Мягкий sage, документ на бумаге и плавающий пульт | Чтение длинных интервью и лекций |

Страница выбора: [`mockups/index.html`](mockups/index.html).

## Что есть в каждом макете

- Три рабочих экрана: **Файлы**, **Транскрипция**, **Экспорт**.
- Drag-and-drop и отдельная кнопка выбора файлов.
- Очередь из нескольких файлов, обработка по одному.
- Две шкалы прогресса: текущий файл и общая готовность очереди.
- Группировка расшифровки по файлам.
- Экран первого запуска с разрешением на загрузку Parakeet V3 и пояснением, что модель скачивается один раз.
- Настройки папки результатов и статус локальной модели.
- Состояния «Пауза» и «Продолжить», запуск очереди, демонстрационные уведомления об экспорте.

Все интерактивные состояния работают в браузере: переключение экранов, пауза, старт, модальные окна и имитация загрузки модели.

### Ограничения прототипов

- Выбор файлов и папки только показывает системный диалог/уведомление — реальная очередь не меняется.
- Прогресс расшифровки статичен, кроме паузы/продолжения.
- Разрешение на загрузку модели не сохраняется между перезагрузками страницы: это макет, а не приложение.
- Пути к папкам показаны в формате macOS; в Tauri-приложении они будут строиться через нативные API текущей ОС.

## Структура

```text
mockups/
  index.html          # страница выбора направления
  01-tape-room.html
  02-editorial.html
  03-console.html
  04-quiet.html
  assets/
    base.css          # общие примитивы
    base.js           # навигация, модальные окна, демо-состояния
    favicon.svg
    fonts/            # вендорные woff2 + fonts.css
    icons/lucide.svg  # один спрайт Lucide на все макеты
    shots/            # скриншоты, которые использует index
  css/
    index.css
    01-tape-room.css
    02-editorial.css
    03-console.css
    04-quiet.css
scripts/
  fetch-mockup-assets.py  # пересобирает шрифты и иконки
  preview.sh
docs/
  mockups.md          # сценарии и состояния прототипов
```

## Дальше

После выбора направления:

1. Зафиксировать поведение и архитектуру Tauri-приложения.
2. Собрать каркас: три рабочих окна/раздела, настройки, первый запуск.
3. Подключить локальный запуск Parakeet V3 и очередь файлов.
4. Добавить кроссплатформенную сборку и проверку на macOS, Windows и Linux.

Можно выбрать макет целиком или смешать элементы — например, взять экран файлов из «Пульта», чтение из «Редакции» и нижнюю панель из «Тихой комнаты».
